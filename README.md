Stellar Burgers API Tests

Автоматизированные API-тесты сервиса Stellar Burgers с использованием:
- Python
- Pytest
- Requests
- Allure

Тесты проверяют корректность работы основных API-эндпоинтов сервиса.

📌 О проекте
Проект покрывает следующие API-сценарии:

Пользователь
- создание пользователя
- создание уже существующего пользователя
- создание пользователя без обязательного поля

Авторизация
- логин существующего пользователя
- логин с неверными данными

Изменение данных пользователя
- изменение данных с авторизацией
- изменение данных без авторизации
- изменение email
- изменение имени

Заказы
- создание заказа с авторизацией
- создание заказа без авторизации
- создание заказа с ингредиентами
- создание заказа без ингредиентов
- создание заказа с неверным хешем ингредиентов

Получение заказов пользователя
- получение заказов авторизованным пользователем
- попытка получения заказов без авторизации

🚀 Установка
Установить зависимости:
pip install -r requirements.txt

▶️ Запуск тестов
- Запуск всех тестов:
pytest

- Запуск с подробным выводом:
pytest -v

📊 Allure отчёт
Сформировать результаты:
- pytest --alluredir=allure-results

Открыть отчёт:
- allure serve allure-results

🔐 Тестовые данные
Для обеспечения независимости тестов:

- тестовые пользователи создаются перед тестом
- после выполнения теста пользователь удаляется через API


⚙️ Особенности реализации
🔹 Независимость тестов

Каждый тест:
- создаёт собственные тестовые данные
- удаляет их после выполнения

🔹 Разделение по эндпоинтам
Тесты сгруппированы по классам:

TestCreateUser
TestLoginUser
TestUpdateUser
TestCreateOrder
TestGetUserOrders

🔹 Проверки
В каждом тесте проверяется:
HTTP статус код
тело ответа

📌 Примечание
Для реализации тестов использовалась официальная документация API сервиса Stellar Burgers.
